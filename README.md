# brain-tumor-segmentation-3d-unet
A Python-based 3D U-Net system for automated brain tumor segmentation from multi-modal MRI scans (T1, T1ce, T2, and FLAIR). Supports data loading and preprocessing, model training, Dice-based evaluation of Whole Tumor (WT), Tumor Core (TC), and Enhancing Tumor (ET), plus segmentation visualization and an interactive application.
